DuoSL - come avviare il test in standalone
============================================

1) AMBIENTE PYTHON (una tantum)
   Serve Python 3.11 (mediapipe/tensorflow non supportano ancora versioni piu' recenti).
   Crea un ambiente virtuale e installa le dipendenze:

     python -m venv venv
     venv\Scripts\activate          (Windows)
     source venv/bin/activate       (Mac/Linux)
     pip install -r requirements.txt

2) AVVIA IL SERVER
   Dalla cartella principale del progetto, con l'ambiente attivo:

     uvicorn server:app --host 0.0.0.0 --port 8000 --reload

3) APRI NEL BROWSER (serve una webcam vera, non funziona in browser sandbox/headless)
   http://localhost:8000/
   Dal menu iniziale scegli "Lessons" oppure "Free Training".
   Premi "Start Camera" e concedi il permesso webcam.

4) COME FUNZIONA IL RICONOSCIMENTO
   L'indicatore in alto a sinistra sul video mostra lo stato:
     - "Not Capturing" (pallino rosso): sei fermo, non sta registrando
     - "Capturing" (pallino verde): ha rilevato movimento e sta accumulando i frame
   Accanto c'e' un numero: e' il valore di movimento in tempo reale (serve per la taratura).

   Il modello NON viene interrogato ad ogni frame: accumula i frame mentre ti muovi
   e classifica UNA volta sola quando ti fermi, sul gesto completo. Quindi il verdetto
   arriva quando finisci il segno, non mentre lo stai facendo.

5) MODALITA' LEZIONE
   Una lezione e' una sequenza di segni. Il campo di testo dice quale fare
   ("Step 1/3 - Fai: HELLO"). Quando lo esegui correttamente conferma
   ("OK Step 1/3 - HELLO corretto!") e dopo un attimo passa al successivo.
   URL diretto di una lezione: http://localhost:8000/?lesson=<nome_file_senza_json>

6) TARARE LA SENSIBILITA' (file server.py, sezione "costanti tunabili")
     MOVEMENT_ENTER_THRESHOLD  -> quanto movimento serve per iniziare a catturare
     MOVEMENT_EXIT_THRESHOLD   -> sotto quale valore si considera che ti sei fermato
     ENTER_FRAMES / EXIT_FRAMES-> quanti frame consecutivi servono per iniziare/chiudere
     MIN_CAPTURE_FRAMES        -> catture piu' corte di cosi' vengono scartate
     REQUIRE_HAND              -> se True non cattura senza almeno una mano inquadrata
   Guarda il numero di movimento mostrato a schermo stando fermo e facendo un segno,
   e regola le due soglie di conseguenza. Poi riavvia il server.

7) CREARE UNA NUOVA LEZIONE
   Copia lectures/test_lesson.json, cambia:
     "id": deve combaciare col nome del file (senza .json)
     "steps": lista di segni, il campo "gloss" deve esistere in
              models/index_to_gloss_200.json (vocabolario del modello, ~209 segni in inglese)

8) FERMARE IL SERVER
   Ctrl+C nel terminale dove gira uvicorn.

NOTA: non serve nessuna API key ne' file .env - il server non usa servizi esterni.
