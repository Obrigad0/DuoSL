DuoSL - come avviare il test in standalone
============================================

1) AMBIENTE PYTHON (una tantum)
   Serve Python 3.11 (mediapipe/tensorflow non supportano ancora versioni piu' recenti).
   Crea un ambiente virtuale e installa le dipendenze:

     python -m venv venv
     venv\Scripts\activate          (Windows)
     source venv/bin/activate       (Mac/Linux)
     pip install -r requirements.txt

2) AVVIA IL SERVER
   Dalla cartella principale del progetto, con l'ambiente attivo:

     uvicorn server:app --host 0.0.0.0 --port 8000

3) APRI NEL BROWSER (serve una webcam vera, non funziona in browser sandbox/headless)
   - Modalita' lezione:  http://localhost:8000/?lesson=test_lesson
   - Modalita' libera (riconosce qualsiasi segno, nessun target): http://localhost:8000/
   Premi "Start Camera" e concedi il permesso webcam.

4) COSA ASPETTARSI IN MODALITA' LEZIONE
   Il campo messaggio mostra: Step 1/3 - Target: HELLO - Accuracy: X% - Hold: Y%
   Mantieni il segno target: se l'accuracy resta sopra soglia, Hold sale al 100%
   e si passa da solo al segno successivo. A fine lezione: "Lesson complete!".

5) TARARE LA SENSIBILITA' (se l'accuracy non sale mai / sale troppo facile)
   File: utils/lesson_engine.py, righe in alto:
     HOLD_SECONDS = 1.5          -> quanti secondi tenere il segno per avanzare
     CONFIDENCE_THRESHOLD = 0.5  -> soglia minima di accuracy per contare come "giusto"
   Modifica il valore, salva, riavvia il server (o aggiungi --reload al comando uvicorn).

6) CREARE UNA NUOVA LEZIONE
   Copia lectures/test_lesson.json, cambia:
     "id": deve combaciare col nome del file (senza .json)
     "steps": lista di segni, il campo "gloss" deve esistere in
              models/index_to_gloss_200.json (vocabolario del modello, ~209 segni in inglese)
   Poi apri: http://localhost:8000/?lesson=<nome_file_senza_json>

7) FERMARE IL SERVER
   Ctrl+C nel terminale dove gira uvicorn.

NOTA: serve un file .env nella cartella principale con dentro una riga
      API_KEY=qualsiasi_valore
      (il client OpenAI viene creato all'avvio ma non e' usato da queste
      funzionalita', un valore finto va benissimo)
