# DuoSL: an interactive program for learning Sign Language (DEMO)

This repository is the demo of a project implementing a large language model for Sign Language interactive learning, based on the live ASL translation system from [tobp03/live-asl-translation](https://github.com/tobp03/live-asl-translation).

The program consists of a Duolingo-style mini-game that guides users through short lessons in Sign Language, providing real-time feedback on their gestures using a deep learning model.

> **Note:** This is a demo/proof-of-concept. It is not a full-fledged learning platform, but rather a prototype to explore how real-time sign recognition can be used for interactive education.
